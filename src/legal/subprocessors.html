Status is stated honestly. Some entries are contracted and carrying live data today. Others are provisioned for a capability that is not switched on yet. A subprocessor list that names a vendor we do not use is as misleading as one that omits a vendor we do, so the status column says which is which, and the date above says when it was last checked.

What we require of them

  • Each subprocessor is bound by a written agreement that limits use of the data to providing its service to us.
  • None of them is permitted to sell personal data, or to use it for their own advertising.
  • We do not permit a subprocessor to use data about a child for targeted advertising, or to train a model on it.

Where data is processed

All subprocessors listed are United States entities and process data in the United States. If that changes, this page changes with it.

Changes

We will update this page before a new subprocessor begins processing personal data, or when one is removed. If you want to be told when it changes, email support@sporv.ai and we will add you to the notification list.
